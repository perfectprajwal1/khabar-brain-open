# Humanizer

Second pass, always a separate request from the script writer.

- Goal: sounds like a friendly young Nepali creator talking to one friend, not a translation and not a news bulletin.
- Keep: the number of lines, every fact and number, claim ids, emotion labels, Devanagari only.
- Do: shorter sentences, spoken word order, light natural fillers used sparingly (हेर्नुस्, ल, ए), contractions the way people speak.
- Do not: add facts, add slang you are not sure about, make a serious line jokey, exaggerate certainty, or change a qualifier.
- The brain code copies claim ids and emotions back from the script writer, so the humanizer cannot change them. The validator re-checks the final lines.
