# Topic picker (automatic)

The brain picks the topic itself. Nobody passes one in unless they want to override.

- Candidates come only from `assets/source_pack.json` (curated official pages, 2 different publishers each). Default pick rotates by date so the same topic does not repeat back to back. A topic id or words typed into the trigger overrides it.
- Lane: useful digital skills for Nepali students and early-career workers. Never news, politics or sports.
- Prefer topics that can be shown in 15 to 20 seconds on screen and that a viewer can try the same day.
- A topic from the pack is a curated choice, not a measured trend. Never call it a Nepal trend. If a dated, location-specific signal is added later, record platform, region, metric and date.
- To add topics: add an entry to the source pack with 2 reachable pages from different publishers. The validator will fail the draft if a quote cannot be found in the fetched text.
