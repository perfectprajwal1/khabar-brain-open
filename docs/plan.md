# Working plan

## Starting lane

Make short Nepali explainers about useful digital skills for students and early-career workers. This lane is not news, politics, or sports.

The examples in the starting note are idea seeds, not approved scripts or proof of demand:
- A ChatGPT prompt that changes the answer.
- A phone setting that saves time.
- A common CV mistake.

The starting note describes an opportunity ranking, not a verified chart of Nepal's top trending niches. Do not describe any topic as Nepal's top trend unless a dated, location-specific source supports that claim. Global or non-Nepal signals must be labeled as such. No view or viral result is promised.

## Draft pipeline shape

1. **Topic scout:** shortlist useful digital-skill topics. Record each signal's platform, location, metric, and observation date. Reject news, politics, and sports.
2. **Research ledger:** connect every factual script claim to reliable evidence. Keep source facts separate from local-fit inferences.
3. **Spoken-Nepali editor:** make the lines easy to say while preserving the facts, meaning, and source trail.
4. **Hook scorer:** check the first line for clear meaning, curiosity, Nepal relevance, and a specific payoff. Treat the score as an editorial aid, not a view forecast.
5. **Icon and motion director:** map lines to a small, consistent set of licensed visual cues.
6. **Validator:** eventually fail drafts with unsupported claims, missing citations, a misleading hook, or an unrecorded icon license. The current validator is a placeholder and validates nothing.
7. **Join:** `scripts/compose_split.py` joins the screen demo, the face clip and the caption into a 1080x1920 draft.

The five draft prompts live in `skills/`. They are text only and are not connected to Gemini.

## Not done

No posting, no scheduling, no paid services. Drafts are always reviewed by a human.
